# AI Language Translator

A translation web app built with **React (Vite)** and **FastAPI (Python)**.
Type or paste text, pick the source and target languages, and get the translation with **Copy** and **Listen (text-to-speech)** buttons.
Translation is done by the free **MyMemory Translation API** (no API key needed).

## Features

- 24 languages plus automatic language detection
- Swap languages, clear, character counter (5000 max), Ctrl/⌘ + Enter to translate
- Copy to clipboard and text-to-speech: audio is generated by the backend with `gTTS` (works for any language, needs internet), with the browser's own voices as a fallback
- Loading spinner, clear error messages, right-to-left support (Urdu, Arabic, Persian), dark mode, mobile layout
- Long text is split into chunks automatically, and paragraphs are preserved

## Setup

You need **Python 3.10+** and **Node.js 18+**.

### 1. Backend

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

Check it works: open http://localhost:8000/docs (interactive API docs).

### 2. Frontend (in a second terminal)

```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. No API key is needed.

## API

`POST /translate`
```json
{ "text": "Hello, how are you?", "source": "auto", "target": "ur" }
```
Response:
```json
{ "translatedText": "...", "source": "auto", "target": "ur", "detectedSource": "en" }
```
`source` can be `"auto"` to detect the language.

`POST /speak` takes `{ "text": "...", "lang": "ur" }` and returns an MP3 (made with gTTS).

`GET /languages` returns the supported languages.

## How it works

1. The React app loads `/languages` and fills the dropdowns.
2. On **Translate**, it POSTs the text and language choices to FastAPI.
3. FastAPI validates the request, splits long text into chunks, calls the MyMemory API, and returns JSON.
4. React shows the result. **Copy** uses the Clipboard API. **Listen** asks the backend (`/speak`) for an MP3 and plays it; if that fails, it falls back to the browser's speech synthesis.

## Troubleshooting

- **"Cannot reach the translation server"**: the backend is not running on port 8000.
- **Listen shows "needs the gTTS package"**: run `python -m pip install -r requirements.txt` and restart the backend.
- **Listen is silent**: speech is made by gTTS and needs an internet connection. Check your volume and sound output, and that the tab isn't muted.
- **Daily limit reached**: MyMemory's free tier has a daily limit. Set `MYMEMORY_EMAIL` in `backend/.env` (copy `.env.example`) for a higher limit, or try again tomorrow.
- **Deploying**: build the frontend with `npm run build`, host the `dist/` folder, set `VITE_API_URL` to your backend URL at build time, and add that frontend URL to `ALLOWED_ORIGINS` in the backend `.env`.
